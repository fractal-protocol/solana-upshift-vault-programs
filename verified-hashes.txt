# Columns (whitespace-separated):
#   program     — the crate/library name passed to `--library-name`.
#   exec_sha256 — `solana-verify get-executable-hash` (trailing zero bytes

#                 on-chain program, so this is the value used for on-chain
#                 verification and asserted by the `reproducible-build` CI job.
#   raw_sha256  — `shasum -a 256` of the full .so (byte-for-byte artifact identity).
#   size        — byte length of the .so.
#
# On an intentional bytecode change, update this file in the SAME PR; CI fails
# if a rebuilt hash disagrees. Reproduce locally: see VERIFY.md.

# Provenance: these values are not self-attesting — the authority is the
# `reproducible-build` CI job, which rebuilds from the commit under test and
# fails on any disagreement. A green run on a commit is what establishes that
# these hashes belong to that commit. That job also fails closed if this file
# yields no records to compare, so a truncated file cannot pass silently.
#
